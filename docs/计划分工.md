## 0. 协作方式（重要）

- **阶段一（代码拆分）在本对话进行**；若本对话上下文不够进入阶段二，再换对话处理阶段二。
- **风格**：阶段一先拆出 A 类（纯搬运，改动风险最低），进度可控后进入 B 类微调，最后 C 类核心重写。
- **契约冻结**：任何模块的对外接口以《重构方案.md》§7 为准，未经评审不得发明/改名/改签名。

```

   ↓
```
