## 覆盖与判断

- 单对单金额不同/缺失/非法仍成组；a/b/不明分类隔离，混合邮件不套用数量例外。
- Decimal/ROUND_HALF_UP、两位与四位混合、整数精度、尾零保留；原始差值 0.49/0.50/0.51/0.5049，正反方向，调用方低 Decimal 精度。
- 相等候选优先，多个候选按尾缀消歧；没有金额候选时按明确尾缀兜底，包括缺失和超容差。
- 不按最近金额、票号、销售方或内部存盘名配对；空尾缀、不相等尾缀、非唯一尾缀待核。
- 一对一竞争全部撤回，独立匹配保留；反转候选、文件及记录顺序结果稳定。
- 来源缺失/重复、跨邮件来源及端口数据不一致不生成关系；重复调用不重复累积 JSON 原因。
- 匹配金额保留行程单原值；已有待核不被清除；旅行字段缺失不借其他单补齐；全部行程单四字段持久化。
- 真实阶段端口自动加载；模拟 IMAP/逐文件提取 → 来源检查 → JSON/八列 Excel，含全缺发票保留 JSON 但不入表、行程单独立不成行、不跨邮件匹配。
- 新增边缘括号/分隔符的全半角归一化及内部尾缀字符保留验证；新增实际匹配关系依次交给仲裁、校验的验证，后续待核不会因已匹配而被豁免。
