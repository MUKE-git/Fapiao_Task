# T3-7 邮件正文下载链接规格（研发稿）

日期：2026-10-15。归属《计划分工》T3-7，对应最终图 B→D→C。链接是**获取文件的途径**，不是凭证类型；取得的 PDF/XML/OFD/图片/ZIP 与直接附件进入同一登记、MD5 去重、处理器及来源链。用户提供的三条下载链接在 2026-10-13 检查时可取到同票 XML/PDF/OFD，这不保证未来可用，也不表示项目下载链已运行。

## 1. 发现候选链接

- 遍历邮件 `text/plain` 正文和 `text/html` 中的锚点 `href`，按 MIME 字符集解码并还原 HTML 实体；保留链接文本与所在邮件的 `mail_id`/UID/主题/Date 头。正文没有附件才查看链接的旧分支要扩展：**附件和链接可同时存在**，两者都要登记后统一去重。
- 只把明确指向票据下载的 HTTP(S) 候选送下载器：可由锚文本“发票 XML/PDF/OFD 文件下载”、允许的文件后缀、`jflx=xml/pdf/ofd` 等信号识别。一般网页、追踪像素、退订链接和邮件签名中的任意 URL 不能全部抓取。链接文字和参数只是候选线索，最终格式按响应字节检查。
- 对用户 C 组样本，三条 URL 使用同一发票号码但 `jflx` 分别指向 XML、PDF、OFD；应尝试取得三份，再按内容和 T3-6 关系处理，不能因 URL 主路径相同只留第一条。HTML `&amp;`、邮件中转义的 `\&` 和尾部标点须正确处理，不能把签名参数截断。

## 2. 受控下载和真实格式检查

| 环节 | 研发规则 |
|---|---|
| URL | 只允许 `https`（确需 `http` 的站点由技术负责人显式列入受控例外）；拒绝 URL 中的用户名/密码、本地文件、非 HTTP(S) scheme。完整 URL 可在内存使用，页面、JSON、日志不得输出含 `sign`/令牌的查询参数。 |
| 目标地址 | 每次请求及每次重定向都解析主机并拒绝回环、私网、链路本地、云元数据等非公网目标；限制重定向次数，防止转发后进入内网。连接目标与已核查地址一致，防 DNS 重绑定。TLS 证书验证不得关闭。 |
| 资源预算 | 设置连接/读取超时、单文件字节上限、邮件与全轮下载数/总字节上限；流式写入临时文件，达到上限立即停止。ZIP 解包沿用附件链的路径与解压大小限制。具体数值由研发根据部署资源压测后固定在配置与测试中。 |
| 响应 | HTTP 成功码仅表示服务器响应；仍检查 `Content-Type`、`Content-Disposition`、魔数与格式解析。`200 text/html` 登录页或错误页不得当作 PDF/OFD/XML。重定向至登录页、过期签名、需交互验证码等均记为链接失败。 |
| 文件名 | 优先使用安全的响应文件名；缺失时由链接类型与本轮序号生成内部名，不包含 `sign` 等参数。完整 URL 不作为 `original_name`；可在内部来源元数据保留脱敏域名/路径标识和获取方式。 |

用户 C 组直接下载检查当时返回 XML 4673 字节、PDF 161064 字节、OFD 94687 字节，均含票号 `26327000000518184747`、日期 `2026-03-13`、金额 `91.61`；这组是**格式与同票关系样本**，不是 HTTP 状态或链接有效期的永久预期。

## 3. 入链、去重与失败回退

下载成功的文件先按真实格式进入公共附件链，分配同邮件唯一 `file_seq`，保留邮件定位及“正文链接取得”的内部来源标记；之后与直接附件、ZIP 解出文件一起做同邮件 MD5 去重。内容相同只处理一份，但来源信息要能解释“本邮件另有链接/附件指向同一内容”；内容不同即使 URL 相似也分别登记。不同邮件不跨邮件 MD5 删除。

单链接失败不阻断其他链接或附件；记录候选链接的脱敏标识、失败环节和原因，页面用 P04/P05 指引用户回原邮件查看，不展示完整签名 URL。仅有失败链接且没有可处理文件时，仍显示原邮件主题和时间；不能假称“没有链接”。下载到不支持格式保留登记并提示，不造发票记录。下载到 XML 但缺票面凭证时按 T3-3/T3-1 标“缺凭证”。

## 4. 当前接口差距与研发交接

现有 `attachment_processor.collect_mail_files` 主要处理直接附件与 ZIP，`pipeline.process_message` 在文件登记之后才调处理器；T3-7 应在这一步之前把正文链接取得的文件汇入同一来源链，避免另造一套编号器。`FileRecord` 目前没有获取方式和脱敏链接标识，研发以兼容方式扩展内部来源元数据及 JSON；下载目录仍属临时工作文件，不进入用户 ZIP。T3-1 页面只展示原邮件主题、邮件时间及有关文件，不新增发件人字段。

受控测试固定脱敏 MIME 邮件正文和本地 HTTP 响应：纯附件、纯链接、附件+链接同内容/不同内容、三格式同票、转义 URL、302 多跳、私网重定向、DNS 变化、超限、超时、HTML 错页、过期签名、不同 `jflx` 同路径。逐项核对登记数、`file_seq`、MD5、解析结果、JSON/Excel、前端提示及 ZIP 清单；真实外站联调另报当次状态，不用一次 HTTP 200 冒充功能验收。
