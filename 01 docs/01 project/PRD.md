# 发票邮件处理系统 PRD


## 一、产品背景与目标

### 1.1 背景
企业报销场景中,员工通过邮件接收电子发票与行程单(如网约车、出租车行程单 + 增值税电子普通发票)。财务/报销人员需逐封打开邮件、下载附件、肉眼识别字段、手动誊抄到报销表,流程重复、易错、耗时。

### 1.2 目标
自动化「收邮件 → 取附件 → 识别字段 → 汇总成表」的全流程,减少人工录入,同时保留人工核查兜底,保证数据可追溯。

### 1.3 非目标
- 不做邮件已读/未读状态管理(不自动标已读)
- 不做发票真伪校验
- 不做报销审批流程
- 不长期存储邮件内容(本机或云端运行结束后按临时工作目录清理规则处理)

## 二、用户角色与场景

| 角色 | 场景 |
|------|------|
| 报销人员 / 财务 | 本机或云端运行，批量处理自己的发票邮件，从页面下载本轮 ZIP |
| 演示 / 评审 | Streamlit Cloud 在线 Demo,填邮箱跑一轮并下载 zip |
| 开发 / 排障 | 查看 task_debug.json 与 agent 日志定位 AI 或附件问题 |

## 三、核心功能需求(用户故事)

### US-1 邮箱登录与收件
- 作为报销人员,我希望填入邮箱账号、授权码并选择 IMAP 服务器(支持 163/QQ/126/Yeah/Gmail/Outlook/自定义),以便程序能连上我的邮箱收件箱。
- 网易邮箱(163/126/yeah)需自动发送兼容的 IMAP ID 指令,QQ 等其他邮箱不发,避免登录失败。
- 登录失败时给出中文原因提示(账号/授权码错误、地址无法解析、SSL 异常、超时等)。

### US-2 未读邮件筛选
- 程序只处理 **IMAP INBOX 未读邮件**,不自动标已读(避免误改邮箱状态)。
- 仅处理主题含「发票 / 报销 / 报销凭证 / 电子发票 / 开票」关键词的邮件,其余整封跳过。
- 无未读邮件或无关键词邮件时,前端明确提示原因,并展示服务器侧 INBOX 邮件总数 / 未读数,便于和网页邮箱对照。

### US-3 附件提取
- 支持 **PDF 直接附件** 与 **ZIP 压缩附件**(递归限 2 层、解出文件 ≤50、总大小 ≤15MB)。
- 同一封邮件内按 **MD5 去重**:直接附件与 ZIP 内重复 PDF 只保留一份,避免重复入库。
- 完整 MIME 解码原名保存在 JSON。内部存盘名使用邮件编号＋文件编号＋安全名；只清理实际存盘名的非法字符，空名或不可用名称使用 Attachment 加序号并保留实际扩展名。完整存盘名最多 120 字符，超长主体截断并加短摘要，编号、扩展名及重名后缀计入长度。

### US-4 文档类型判定
- 类型(Invoice 发票 / Itinerary 行程单 / Unknown)由「预读类型(本地) + AI file_classifications」判定。
- 若附件名含「行程单」关键词优先判为行程单(避免「通行费电子行程单」被误判为发票)。

### US-5 AI 逐文件提取
- 一次调用只处理一个文件，file_classifications 返回与该输入对应的一个分类结果；不整封邮件批量提取。
- 发票提取日期、号码、价税合计、发票类型、票面类型、销售方。行程单保留编号、匹配金额、出行时间、起终点四字段，编号由程序生成；不提取行程单企业名称。
- 出行时间取首笔行程起始时间，起终点取第一段。
- 发票类型非必填，缺失留空，有值校验；其他发票业务字段必填，缺失标记，有值校验。票面类型清理星号及分类简称后检查文字类型、必填和长度，再按交通关键词判 a/b；缺失或格式无效时不能默认 b 类。不做有效值清单及 PDF 票面位置核验，提取值按现有提取规则使用。
- 同邮件仅一张发票和一张行程单时自动成组，不要求金额完整或一致；其他数量组合按金额、完整解码原名匹配。只有 a 类汇入旅行字段。
- 金额保留输入精度最多四位，以 Decimal 计算并保留原始小数位数；不提前舍入两位。JSON 金额用十进制字符串，用户 Excel 显示两位。
- 当前提示词内置 ai_client.py；T3-2 改造模型接入与文本/多模态输入输出接口。

### US-6 兜底与重试
- AI 调用 HTTP 429/5xx 自动重试 2 次(间隔 1s/3s)。
- AI 不可用 / JSON 解析失败 / 缺字段时,用本机正则兜底生成「伪结果」,关键字段缺失标记 FIELD_NOT_FOUND。
- 按单条发票判断：只有票号、日期、金额全部缺失才不入用户 Excel；前端提醒，JSON 保留记录及原因。只缺一项或两项仍入表并提示。缺失与有值但格式错误分别判断。

### US-7 输出与汇总
- 生成「发票信息汇总表.xlsx」,列顺序固定:发票日期、发票号码、报销金额、发票类型、票面类型、出行时间、销售方、出发地/目的地。
- 已存在时追加行(不覆盖),表头缺失时补写。
- task_debug.json 保存每封邮件的文件、发票记录、全部行程单四字段（包括未匹配项）、来源及内部/导出名称映射。结构见《重构方案》§3.3；缺失和校验原因须可关联到记录。
- 行程单不单独进入用户 Excel，只将时间、起终点汇入对应 a 类发票行。
- 同邮件 MD5 去重只去重复附件；发票号码去重只比较本轮记录，不查历史 Excel。

### US-8 用户压缩包文件命名规则
用户下载包只含 `发票信息汇总表.xlsx`、`task_debug.json` 和 `用户票据/` 下的发票、行程单 PDF。XML、OFD、图片可用于识别或转成 PDF，但原格式、原始 ZIP、内部处理目录和日志不交付。以下模板只作用于实际交付的 PDF；内部保留 Msg{序号}_{文件序号}_{安全名}，JSON 保存原来源与交付名对应关系。
- 发票:`{票面类型}+{开票日期}+{金额}元.pdf`
- 行程单:`行程单+{出行日期}+{金额}元.pdf`
- 同一业务凭证有多种格式时优先交付已有 PDF；无 PDF 时，OFD 或图片经转换并检查后可交付 PDF。仅有 XML 而无票面凭证时保留记录并提示“缺凭证”，不生成虚构票面。未知角色文件不交付。具体选择及异常规则见《T3-1_导出与下载规格_待审核.md》。
- 同名文件自动加 (1)(2) 避免覆盖。缺日期、金额、票面类型分别用 `日期缺失`、`金额缺失`、`票面类型缺失`；**金额缺失后不加“元”**。文件名不借其他文件字段。完整导出名最多 120 字符，含后缀；超长加短摘要。

### US-9 人工核查提示
- 前端列出待办:
  1. 本机预读类型与 AI file_classifications 不一致的附件
  2. 关键字段缺失 / AI 异常 / 交通类发票缺行程单 的邮件(附主题与 Date 头时间便于定位)
- 交通类票面类型(客运服务费/通行费/网约车服务费等)若无行程单附件,强制提示。

### US-10 部署模式适配
- **统一交付方式**：无论程序在本机还是云端运行，每轮都在独立临时工作目录处理，页面只提供本轮 ZIP 下载；不再提供桌面输出文件夹、模式切换或“下载备份”入口。本机运行仍可使用页面，但交付方式相同。
- 下载包在显示按钮前生成并核对内容；处理原件和内部目录不进入下载包。打包后按既定清理规则处理临时工作文件，打包失败给出页面提示。
- 页面与日志不展示百炼 API Key。

## 四、业务流程

未读邮件主题筛选 → 附件/ZIP 获取 → 同邮件 MD5 去重、编号 → 逐文件预读与 AI/正则提取 → 形成发票与行程单候选 → 程序匹配 → 本轮发票号码去重仲裁 → 必填/格式校验 → 排除三关键字段全部缺失的发票 → 主流程统一写八列 Excel、完整 JSON → 用户导出副本按业务名命名并打包。
T2 先接 PDF；XML/OFD/图片、下载链接、跨格式组合是 T3，最终目标图见技术设计目录。处理器均不直接写 Excel。

## 五、非功能需求

| 维度 | 要求 |
|------|------|
| 邮箱兼容 | 163/QQ/126/Yeah/Gmail/Outlook + 自定义;网易需 IMAP ID |
| 部署 | 本机或云端运行均用独立临时工作目录，页面统一下载 ZIP；无桌面输出模式 |
| 安全 | API Key 不在页面/日志展示;走环境变量或 .streamlit/secrets.toml |
| 可追溯 | task_debug.json 全量快照 + 04 logs/debug-{run_id}.log agent 日志 |
| 容错 | AI 重试 + 正则兜底;IMAP 异常中文提示;汇总表生成失败给出页面提示 |
| 幂等 | 不自动标已读；每轮独立临时工作目录，重复处理的未读邮件在不同任务中仍可能重复出现 |

## 六、当前技术栈(重构参考)

- 语言:Python 3(带 `from __future__ import annotations`)
- 界面:Streamlit
- 邮件:imaplib(IMAP4_SSL)
- PDF:pdfplumber
- AI:阿里云百炼 dashscope.Generation
- Excel:openpyxl
- 模块分层：app_demo.py 页面 → pipeline.py 主流程 → 附件/PDF 处理器、阶段接口、数据模型和 Excel 写入器；invoice_pipeline.py 仅为兼容过渡层。

| 文件 | 说明 |
|------|------|
| 发票信息汇总表.xlsx | 8 列固定顺序的结构化报销数据 |
