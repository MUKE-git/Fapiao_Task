# T3 流程覆盖与开发分工

产品验收已全部通过。流程以 [主流程图](../02%20technical-design/主流程图mermaid.txt)为准，职责见 [计划分工](计划分工.md)。

| 环节 | 当前行为 | 负责人任务 |
|---|---|---|
| 邮件获取 | INBOX 未读与主题筛选，不自动标记已读 | T2-1 |
| 附件或链接 | 有非 OFD 附件则只走附件；否则检查正文链接。普通 ZIP 本身算附件 | T3-7、T3-9 |
| OFD | 登记前忽略，不提取、转换或交付；仅有 OFD 且无其他可处理内容时提示无有效附件 | 公共附件链 |
| 文件识别 | PDF、XML、图片逐文件返回候选及证据 | T2-1、T3-2、T3-3、T3-5 |
| 组合与匹配 | 同票跨格式组合；再执行行程单匹配、同轮票号仲裁、字段校验 | T3-6、T2-3、T2-4、T2-6 |
| 结果输出 | 八列 Excel、完整 JSON、原 PDF 优先及图片 PDF 副本、精简 ZIP | T3-8、T3-9 |
| 页面 | 临时目录、邮件级提示、下载本轮 ZIP | T3-1 |

测试用例与产品验收分别管理。用例的虚构来源、人工审核状态、真实文件/真实服务使用情况以及运行结果须分别说明；受控返回不能冒充真实识别结果。冻结用例的编号、范围、顺序和预期保持不变。
