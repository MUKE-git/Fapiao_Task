# 项目结构与任务边界

产品验收已全部通过。根目录是当前运行版本；`T1/`、`T2/` 与 `baseline/` 为只读快照，不作为当前应用入口。

## 执行关系

`app_demo.py` 创建本轮临时目录，调用 `pipeline.run_pipeline`，展示状态并提供 ZIP 下载。`pipeline.py` 获取未读邮件，有非 OFD 附件时处理附件，否则检查正文链接；文件登记、去重后按 PDF、XML、图片分流。随后依次进行跨格式同票组合、行程单匹配、同轮去重仲裁、字段校验、八列 Excel 和 JSON 输出、PDF 选择与 ZIP 核查。

## 模块职责

| 模块 | 职责 |
|---|---|
| app_demo.py / config.py | 页面交互、配置读取、邮件登录配置及输出路径 |
| attachment_processor.py / mail_link_downloader.py | 附件与 ZIP 获取、链接下载、格式判断、MD5 去重和来源登记；识别并忽略 OFD |
| pdf_processor.py / xml_processor.py / image_processor.py | 各格式逐文件处理，返回结果，不直接写 Excel |
| model_gateway.py / prompt_loader.py / prompts.txt | 同家族模型配置校验、千问与 DeepSeek 接口适配、外置提示词读取 |
| voucher_matcher.py | 同邮件多格式同票关系、字段来源与冲突 |
| itinerary_matcher.py | 发票与行程单一对一匹配；符合条件时逐轮重算及末尾单对单 |
| dedup_arbitrator.py / field_validator.py | 本轮票号去重仲裁、字段校验 |
| data_model.py / processor_contracts.py / stage_ports.py | 数据结构、处理结果及阶段接口 |
| excel_writer.py / delivery_exporter.py | 八列表格、交付 PDF 选择和业务名、JSON 映射及精简 ZIP |

`ofd_processor.py` 暂保留供现行测试动态引用，生产主流程不调用；保留不代表支持 OFD 提取或转换。根目录旧 `invoice_pipeline.py` 已移除。

## 来源定位

邮件 UID、文件序号、完整原名、内部存盘名、记录来源和导出名通过 JSON 关联。Excel 只含业务列，不能单靠 Excel 反查完整来源。内部名称不代表文件位于交付包内；只有实际选中交付的 PDF 来源填写导出名。
