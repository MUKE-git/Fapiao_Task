## T4／后续迭代需求（待排期）

- **XML 缺失字段未按原要求由同票 PDF／图片补空**：T3-6 原研发要求允许用同票 PDF／图片的唯一可靠值补空；当前实现确认同票且有可靠 XML 票号来源后，只从 XML 取业务字段，XML 缺失字段仍保留缺失，即使 PDF／图片有值也不补填。此项登记为后续修复问题，本轮不修复，不影响已确认的产品验收结论。原要求及后续差异见 [T3-6 规格第 3 节](../02%20technical-design/T3-6_跨格式凭证匹配规格_研发稿.md#3-合并字段和来源优先级)。后续排期时须先确认补空条件、来源证据和冲突处理规则，再制定独立预期并验证，不直接覆盖已审核预期。
